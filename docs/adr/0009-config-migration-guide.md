# ADR-0009：旧配置迁移指南

- Status: Accepted
- Date: 2026-10-12

## 背景与授权

所有者明确要求补充旧版配置迁移文档，并将示例设备款型从 `xxx2` 改为 `galaxy`。本次授权覆盖迁移指南、使用说明入口及对应变更记录，不修改运行时代码或正式产品配置。

## 决策

- 新增 `docs/config-migration-v2.md`，说明旧版 `default` 配置迁移到显式 schema v2，并以 `galaxy` 作为产品键。
- 分别说明结构迁移、产品改名、业务参数保留和插件路径更新；提供主配置、产品配置及验证命令。
- 示例只复用仓内合成模板。真实关键字、正则和产品知识由维护者在 LAN 中从旧配置迁入，不把示例当成真实 galaxy 规格。
- 在 `docs/usage.md` 加入迁移入口。保持 ADR-0006 的单一路径，不恢复 v1 自动转换或 `migrate-config`。

## 验证与回滚

抽取文档配置并用当前 CLI 校验；运行现有配置与解析聚焦测试、完整交付检查和治理门禁。真实 LAN corpus 和 2GB 日志包不属于本次文档验证。

结果记录在 `governance/changes/2026-10-12-config-migration-guide.yaml`。回滚只删除本次新增文档、ADR 和记录，撤回使用说明新增的链接；保留其他修改。未经另行授权，不提交、推送或外传材料。
