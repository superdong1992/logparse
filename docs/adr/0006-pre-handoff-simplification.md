# ADR-0006：移交前精简与单一路径

- Status: Accepted
- Date: 2026-10-12
- 部分替代：ADR-0001 的当前冻结时间点、ADR-0002 的本轮修改限制，以及 ADR-0003 的过渡兼容承诺。

## 背景与授权

仓库所有者确认：原计划在 LAN 内继续维护，但 LAN 尚无后续修改；本轮允许破坏兼容性，并明确允许修改 `logparse-develop`。所有者已批准本次完整精简方案。因此当前工作树可完成移交前重构，不需要为了不存在的 LAN 分叉保留旧实现。

这项授权仅适用于本次精简，不授权提交、推送、外传原始日志或今后的任意架构变更。正式移交之后，LAN 仓库仍是唯一权威来源，禁止向外同步 LAN 代码、配置、样例和日志。

## 决策

- `ParseService` 是唯一完整解析入口。产品引擎负责产品处理；移除旧 `Pipeline`、旧导入 façade 和重复编排。
- 只接受显式 schema v2 配置，运行时直接消费 v2。移除 v1 自动迁移、反向旧结构投影和 `migrate-config`。
- 机制仅支持原生 `execute(MechanismContext) -> MechanismOutcome`，移除 pre-v1 可变结果适配。
- 根 `cli.py` 只负责启动，命令实现放在 `backend/presentation/cli/`。保留解析、查询、目标日志、DFX 和产品接入能力，不承诺已删除的 Python 导入及旧配置接口。
- 保留 default、compact 两套产品及完整链路验收。保持 V3 生命周期、Module1/Module2 关联、CPU0、PID 匹配和产物语义；本次不调整黄色业务算法。
- 删除失效的会话交接、历史实施计划、V2 归档和重复图表；Git 历史及既有 ADR、change record 保留历史依据。
- 诊断 skill 正文统一存放在 `.agents/skills/diagnose-*/`，`.claude/skills/diagnose-*/` 仅提供对应发现入口。两者都属于新增诊断知识的绿区；已有红区与治理硬编码保护不变。生成器和扁平 `result.zip` 打包继续作为诊断集成工具维护，独立于确定性预处理运行时。

## 保留的安全与验证边界

风险分区不降级：红区仍需 Accepted ADR、明确授权、契约/安全/冒烟验证和回滚方案；未知源文件仍为红区；治理路径的硬编码红区保护保留。失效路径分类在本轮删除验收完成前保留，避免删除被误分类。

本次涉及黄色路径的改动仅为导入、接口和测试迁移，使用合成 fixture 回归证明原有行为。没有真实 LAN case，也没有执行真实历史 corpus；不得把合成测试写成真实证据。本次例外由上述用户授权覆盖，并在 change record 中明确记录。将来改变生命周期或关联语义，仍需真实案例、最小 fixture 和历史 corpus 对比。

预处理不调用模型；解压路径安全、产物原子写入、compact `result.json`、严格目标选择和 DFX 上下文限额不变。原始日志不得进入索引、摘要或外发材料。

## 验收与回滚

运行完整交付验证、治理强制门禁、default/compact 冒烟、目标日志及 DFX 验证，并对比精简前后的业务产物和扫描计数。性能结果只记录实际测量，不将小样例结果代替真实 2GB 包验收。

本轮验证和差异记录在 `governance/changes/2026-10-12-pre-handoff-simplification.yaml`。回滚应在批准的本地流程中恢复本轮开始前的基线；有其他并发工作时只回退本轮路径，不覆盖无关修改。
