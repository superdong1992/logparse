模块职责速查

Pipeline6 步管道编排，按产品名加载插件对
TimestampExtractor从文本/文件/LogEntry 提取时间戳，处理 .gz 和 UTF-8/GBK 编码
CycleDetectorindicator 进程 PID 变化 + 序号回绕反向扫描，板卡重启传播到子 CPU
RoleIdentifier机制模块 active_master_keyword 优先，兜底按 ActivePeriod/日志存在性判定
MechOutputWriterslot/周期/cpu_N/ 进程名-PID.log 三层目录落盘
ScannerPlugin发现 diag/slot_*/ 和 varlog/slot_*/ 目录结构，解压内层 varlog.zip
